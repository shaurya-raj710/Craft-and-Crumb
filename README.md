#  Craft & Crumb

*A simple bakery website built as part of my web development learning journey.*

##  About the Project

Craft & Crumb is a small bakery website project that I am building to practise and revise the concepts I learn in my Full Stack Development (FSD) classes.

The main idea is to create a website for a fictional restaurant while learning how different parts of web development work.

I will start with the basics of frontend development using HTML, CSS, and JavaScript. As I learn new concepts, I will try to apply them to this project.

This repository will also help me track my progress and see how my skills improve over time.

## 🎯 Project Goals

- Practise and revise HTML, CSS, and JavaScript.
- Apply concepts learned in FSD classes.
- Improve my understanding of website structure and design.
- Build a small but practical project.
- Learn by writing code and experimenting with different ideas.
- Gradually improve the website as I learn new concepts.
